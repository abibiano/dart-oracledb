# Public API Reference — oracledb (dart-oracledb)

> Generated by the Document Project workflow (deep scan), 2026-06-12. The public
> surface is exactly what `lib/oracledb.dart` re-exports — everything under
> `lib/src/` that is *not* re-exported is private implementation detail.

```dart
import 'package:oracledb/oracledb.dart';
```

## `OracleConnection`

Created only via the static factories (constructor is private; a
`@visibleForTesting` `forTesting` constructor exists for tests).

### Opening

```dart
static Future<OracleConnection> connect(
  String connectString, {        // 'host:port/service', e.g. 'localhost:1521/FREEPDB1'
  required String user,
  required String password,
  TlsConfig? tlsConfig,
  int statementCacheSize = 30,
  bool preserveTimestampTimeZone = false,
  Duration? timeout,
});

static Future<T> withConnection<T>(
  String connectString, {
  required String user,
  required String password,
  required Future<T> Function(OracleConnection conn) callback,
  // ...same options as connect...
});  // opens, runs callback, always closes (try/finally)
```

> Exact optional-parameter names/defaults are defined at
> [connection.dart:884](../lib/src/connection.dart#L884) (`connect`) and
> [connection.dart:985](../lib/src/connection.dart#L985) (`withConnection`).

### Executing

```dart
Future<OracleResult> execute(
  String sql, [
  Object? bindValues,
  OracleExecuteOptions? options,
]);
```

- `bindValues` is a `Map<String, Object?>` for **named** binds (`:name`) or a
  `List<Object?>` for **positional** binds (`:1`, `:2`, …).
- IN binds are plain Dart values; OUT / IN OUT binds are `OracleBind` instances.
- **One in-flight `execute` per connection** — an overlapping call is rejected
  (use a separate connection for concurrency).

`OracleExecuteOptions` (all optional; omitting it is the default eager path):

```dart
const OracleExecuteOptions({
  bool resultSet = false,       // lazy OracleResultSet in result.resultSet
  int? fetchSize,               // resultSet continuation batch size (default 50)
  int maxRows = 0,              // eager row cap; 0 = unlimited
  bool fetchLobs = false,       // CLOB/NCLOB/BLOB as OracleLob handles
  bool rawJsonBlobs = false,    // BLOB IS JSON columns as raw Uint8List
  Set<OracleDbType> fetchAsString = const {}, // date/time columns as String
  OracleFetchTypeHandler? fetchTypeHandler,   // per-column converters
});
```

#### Fetch as string

`fetchAsString` returns the selected date/time column types as `String`
(node-oracledb `fetchAsString` parity for dates and timestamps):

| Entry | Columns converted |
|-------|-------------------|
| `OracleDbType.date` | `DATE` |
| `OracleDbType.timestamp` | `TIMESTAMP`, `TIMESTAMP WITH LOCAL TIME ZONE` |
| `OracleDbType.timestampTz` | `TIMESTAMP WITH TIME ZONE` |
| `OracleDbType.rowid`, `OracleDbType.urowid` | none — accepted as no-ops: `ROWID` / `UROWID` columns already decode to `String` |

- Any other `OracleDbType` → `ArgumentError` (name `options.fetchAsString`)
  before any wire round trip. An empty set (the default) changes nothing.
- **Client-side text.** The column is still fetched natively (Oracle sends
  these types in binary whatever the client asks) and each decoded value is
  converted with its own `toString()`: `DateTime.toString()` for DATE /
  TIMESTAMP / LTZ (`2024-03-05 13:14:15.123456`), the UTC `DateTime` for
  TIMESTAMP WITH TIME ZONE (`2024-03-05 12:14:15.123456Z`), or
  `OracleTimestampTz.toString()` with `preserveTimestampTimeZone: true`
  (offset and `regionId`, never the region name). NLS formats are not
  applied and precision stops at microseconds; select `TO_CHAR(col, 'fmt')`
  for Oracle's exact text.
- SQL `NULL` → `null`; `ColumnMetadata` still reports the database type.
- Scope: the top-level query's rows — `result.rows` (with or without
  `maxRows`) and every batch of a `resultSet: true` result set. REF CURSOR
  OUT bind rows, nested `CURSOR(...)` rows and PL/SQL implicit results keep
  native types; `executeStream()` / `queryStream()` take no options.
- A [fetch type handler](#fetch-type-handler) converter for the same column
  wins over `fetchAsString`.

#### Fetch type handler

```dart
typedef OracleFetchConverter = Object? Function(Object value);
typedef OracleFetchTypeHandler =
    OracleFetchConverter? Function(
      ColumnMetadata column,
      List<ColumnMetadata> columns,
    );
```

`fetchTypeHandler` converts fetched values per column (node-oracledb
`fetchTypeHandler` parity for its **converter** half):

```dart
final result = await conn.execute(
  'SELECT name, salary FROM employees',
  null,
  OracleExecuteOptions(
    fetchTypeHandler: (column, columns) =>
        column.name == 'SALARY' ? (value) => value.toString() : null,
  ),
);
result.rows.first['SALARY']; // '7000'
```

- **Handler:** called exactly once per result column, in column order, with
  the column's `ColumnMetadata` and an unmodifiable list of all result
  columns, before any row is converted. Returns the column's converter, or
  `null` to keep the default. Called on every call (nothing is cached with
  the statement), so a cached re-execute with a different handler, or none,
  returns that call's own representation. Always returning `null` = option
  omitted.
- **Converter:** called synchronously, once per non-NULL cell, on every fetch
  round (`result.rows` with or without `maxRows`; every `resultSet: true`
  batch — Oracle's duplicate-column copies across rounds are converted from
  the decoded value, never re-converted). Receives the decoded value
  (`int`/`double`, `String`, `Uint8List`, `DateTime`, `OracleTimestampTz`,
  `OracleIntervalDS`, `OracleIntervalYM`, the rowid `String` for ROWID /
  UROWID, JSON `Map`/`List`/scalar, `List<OracleRow>` for a nested `CURSOR(...)`
  column, `String`/`Uint8List` for CLOB/BLOB or `OracleLob` under
  `fetchLobs`); its return value (any `Object?`) becomes the cell. SQL `NULL`
  → `null`, converter not called. A returned `Future` is not awaited.
- **No `type`:** the fetch type cannot be changed — columns are fetched
  natively (no DEFINE, no SQL rewrite) and converted client-side, never with
  NLS formatting; use `TO_CHAR(col, 'fmt')` for Oracle's own text.
  `ColumnMetadata` still reports the database type.
- **Precedence:** a converter wins over [`fetchAsString`](#fetch-as-string)
  for its column; `fetchAsString` still applies where the handler returned
  `null`.
- **Errors:** anything the handler or a converter throws is rethrown
  unchanged (not wrapped in `OracleException`); no rows of the failed call or
  result-set batch are returned; the connection stays usable (a failed
  `resultSet` still needs `close()`).
- **`fetchLobs: true`:** the converter receives the `OracleLob`; it remains the
  caller's to close (`closeLobs()` only finds handles still in the rows). A
  result set's `close()` still reaps handles of rows never retrieved.
- **Scope:** top-level query rows only — never called for REF CURSOR OUT
  binds, rows inside a nested `CURSOR(...)` column, PL/SQL implicit results,
  OUT binds, DML or PL/SQL; no connection-level or global handler;
  `executeMany()` / `executeStream()` / `queryStream()` take no such option.
- **From node-oracledb:** return the converter itself (not
  `{converter: fn}`); `{type: ...}` has no equivalent; `metaData.dbType` →
  `ColumnMetadata.oracleType` (an Oracle type code).

### Transactions

```dart
Future<T> runTransaction<T>(Future<T> Function(OracleConnection conn) action);
Future<void> commit({Duration timeout = const Duration(seconds: 30)});
Future<void> rollback({Duration timeout = const Duration(seconds: 30)});
```

`runTransaction` runs `action`, commits on success, rolls back on throw. Nested
`runTransaction` is **not** supported (throws).

### Time-zone region names

```dart
Future<String?> timeZoneRegionName(OracleTimestampTz value);
```

Resolves `value.regionId` to the region name as Oracle's `TZR` element renders
it (e.g. `'EUROPE/MADRID'`), from **this connection's database** — never a
bundled table. The first lookup reads `V$TIMEZONE_NAMES` (readable by `PUBLIC`
by default) in one query and caches the id → name map for the connection's
lifetime; later lookups need no round trip. That first lookup is a normal
connection operation, so it is rejected while another operation (an open
`OracleResultSet`, an in-flight `execute`) holds the connection.

- `value.regionId == null` (a numeric offset) → `null`, with no query.
- An id absent from the server's table → `OracleException`, error code 1882
  (ORA-01882) — never a guessed name or `null`.
- `V$TIMEZONE_NAMES` unreadable → `OracleException` carrying the server's
  code (e.g. ORA-00942), message naming the view. A failed load is not
  cached.
- Works on any connection (no `preserveTimestampTimeZone` needed), including
  for hand-built values; ids follow the server's time-zone file, so resolve a
  value against the database it came from.
- Textual alternative: `OracleExecuteOptions(fetchAsString:
  {OracleDbType.timestampTz})` returns the column as text rendered by the
  driver (`OracleTimestampTz.toString()` in preserve mode, which shows the
  `regionId`, not the name); `TO_CHAR(col, '... TZR')` in SQL gives Oracle's
  own text with the region name. See [Fetch as string](#fetch-as-string).

## `OracleResult` / `OracleRow`

```dart
result.rows;             // List<OracleRow>  (SELECT)
result.rowCount;         // int
result.columns;          // List<ColumnMetadata>
result.columnNames;      // List<String>
result.rowsAffected;     // int? — DML count; null for SELECT, and null (not 0) on pre-12.2 servers
result.outBinds;         // OracleOutBinds — PL/SQL OUT/IN OUT values
result.moreRowsAvailable;// bool — true if the FETCH cap or a missing cursor truncated the rows

row['NAME'];  row['name'];  row[0];   // by column name (case-insensitive) or index; null if absent/NULL
row.toList(); row.toMap();
```

**Oracle NULL convention:** an empty `VARCHAR2` (`''`) round-trips as `null`, not
a zero-length string (`'' IS NULL` in Oracle).

## Binds — `OracleBind`, `OracleDbType`, `OracleOutBinds`

```dart
OracleBind.out({ required OracleDbType type, int? maxSize });
OracleBind.inOut({ required Object? value, required OracleDbType type, int? maxSize });
```

`maxSize` is **required** for `varchar`, `raw`, `clob`, `blob`, `json` (and must
be `> 0`); numeric/date/timestamp use fixed protocol sizes. IN OUT values are
type-checked at construction (fails at the call site, not deep in wire encoding).

**`OracleDbType` and its `maxSize` units / Dart mapping:**

| `OracleDbType` | Dart type | `maxSize` unit | Notes |
|----------------|-----------|----------------|-------|
| `number` | `int` / `double` | — | NUMBER can exceed Dart `int`; rejects NaN/Inf |
| `varchar` | `String` | bytes | requires `maxSize` |
| `date` | `DateTime` | — | 7-byte; also a `fetchAsString` entry (DATE columns) |
| `timestamp` | `DateTime` | — | 11-byte, µs precision; also a `fetchAsString` entry (TIMESTAMP and LTZ columns) |
| `timestampTz` | `DateTime` (UTC) or `OracleTimestampTz` | — | offset (or a named region's `regionId`) preserved only with `preserveTimestampTimeZone: true`; `regionId` ignored on bind; also a `fetchAsString` entry (TSTZ columns) |
| `raw` | `Uint8List` | bytes | requires `maxSize` |
| `clob` | `String` | **characters** (UTF-16 units) | wire = LOB locator; `'' → NULL` |
| `blob` | `Uint8List` | bytes | wire = LOB locator; empty `Uint8List` → empty BLOB (≠ NULL) |
| `json` | `Map<String,Object?>` / `List<Object?>` / scalar | **OSON bytes** | Oracle 21c+; members (and, with this declared type, a scalar root): null/bool/num/String/`DateTime`/`OracleTimestampTz`/`Uint8List`/nested map+list — everything a JSON fetch returns |
| `intervalDS` | `OracleIntervalDS` (decoded); `OracleIntervalDS` or `Duration` (input) | — | 11-byte INTERVAL DAY TO SECOND; a `Duration` binds at microsecond resolution; not a `fetchAsString` entry |
| `intervalYM` | `OracleIntervalYM` | — | 5-byte INTERVAL YEAR TO MONTH; no Dart-native input type; not a `fetchAsString` entry |
| `rowid` | `String` | — | ROWID text (`ROWIDTOCHAR`); travels as VARCHAR with a fixed 3950-byte buffer (`maxSize` ignored); a plain `String` IN bind needs no declaration; a no-op `fetchAsString` entry |
| `urowid` | `String` | — | UROWID text (a logical rowid starts with `*`); same wire shape as `rowid`, and either receives physical and logical rowids |

**Reading OUT binds:**

```dart
result.outBinds['name'];   // by name (case-insensitive); null if absent or SQL NULL
result.outBinds[0];        // by zero-based index over OUT/IN OUT outputs only
result.outBinds.toList();  result.outBinds.toMap();
// keys must be int or String, else ArgumentError
```

## `OracleException`

```dart
final int     errorCode;   // numeric ORA code (e.g. 1017)
final String  message;     // human-readable; ≤200-char snippet for query errors
final Object? cause;       // preserved originating error
final String? sql;         // full SQL (placeholders kept; bind values never substituted) — query errors only
final int?    offset;      // char offset into sql reported by Oracle — query errors only
String get code;           // 'ORA-01017' (5-digit pad floor); negative → 'ORA-invalid(<code>)', never throws
```

**Well-known code constants** (selection): `oraInvalidCredentials` (1017),
`oraConnectionClosed` (3113), `oraNetworkError` (12150), `oraConnectTimeout`
(12170), `oraConnectionRefused` (12514), `oraHostUnreachable` (12541),
`oraTlsHandshakeFailed` (28860), `oraTlsCertificateError` (28862),
`oraBindMismatch` (1008), `oraBindTypeError` (6502); plus protocol codes
`oraMalformedPacket`, `oraProtocolViolation`, `oraUnsupportedType`,
`oraDataTypeNotSupported`.

## `OracleTimestampTz`

```dart
OracleTimestampTz(DateTime utc, {required int offsetMinutes, int? regionId});
OracleTimestampTz.fromHourMinute(DateTime utc, int hour, int minute, {int? regionId});
OracleTimestampTz.fromOffset(DateTime utc, Duration offset, {int? regionId});
final DateTime utc;        // absolute instant
final int offsetMinutes;   // reported offset, -779..840; 0 for a decoded region value
final int? regionId;       // server region id 0..8191 for a named region; null for an offset
```

Wrapper that preserves a numeric offset of a `TIMESTAMP WITH TIME ZONE`
(default decode collapses to a UTC `DateTime`). Opt in per connection with
`preserveTimestampTimeZone: true`; it then applies to both column decode and
OUT/IN OUT binds (JSON members are always this type). A value stored with a
named region (e.g. `Europe/Madrid`) decodes to its correct UTC instant at a
`+00:00` offset — the region's offset is never computed — with the server's
region id in `regionId`; `OracleConnection.timeZoneRegionName` resolves it to
the name. `regionId` outside 0..8191 throws `ArgumentError`. `==`, `hashCode`,
`compareTo` (instant, then offset, then region id; `null` first) and
`toString` include `regionId`. Binding is offset-only: `regionId` is ignored,
so a decoded region value binds back at `+00:00` without its region. See
[oracle_timestamp_tz.dart](../lib/src/oracle_timestamp_tz.dart).

## `OracleIntervalDS`

```dart
OracleIntervalDS({int days = 0, int hours = 0, int minutes = 0, int seconds = 0, int fseconds = 0});
OracleIntervalDS.fromDuration(Duration duration);
final int days, hours, minutes, seconds; // normalized, one shared sign
final int fseconds;                       // fractional seconds in nanoseconds
Duration toDuration();                    // sub-microsecond digits truncated
```

`INTERVAL DAY TO SECOND` value (node-oracledb `IntervalDS` parity). The
constructor carries seconds → minutes → hours → days with truncating division
(`fseconds` is never carried) and throws `ArgumentError` outside
`INTERVAL DAY(9) TO SECOND(9)` (±999,999,999 days or ns) or when components
mix signs (Oracle stores those verbatim and renders them inconsistently).
`==`/`hashCode` compare the normalized components; `toString()` renders
`OracleIntervalDS(+3 04:05:06.123456789)`. `toDuration()` throws `RangeError`
beyond a `Duration`'s range (about ±106.75 million days). Binds as
INTERVAL DAY TO SECOND (inferred, or `OracleDbType.intervalDS`), as does a
plain `Duration`. See [oracle_interval.dart](../lib/src/oracle_interval.dart).

## `OracleIntervalYM`

```dart
OracleIntervalYM({int years = 0, int months = 0});
final int years;  // normalized, -999,999,999..999,999,999
final int months; // -11..11, never the opposite sign of years
```

`INTERVAL YEAR TO MONTH` value (node-oracledb `IntervalYM` parity). The
constructor carries every 12 months into a year with truncating division
(`months: 14` is years 1, months 2) and throws `ArgumentError` outside
`INTERVAL YEAR(9) TO MONTH` (±999,999,999 years and 11 months) or when the
components mix signs (Oracle stores those verbatim and renders them
inconsistently). `==`/`hashCode` compare the normalized components;
`toString()` renders `OracleIntervalYM(+3-05)`. Binds as INTERVAL YEAR TO
MONTH (inferred, or `OracleDbType.intervalYM`); no Dart-native type does. See
[oracle_interval.dart](../lib/src/oracle_interval.dart).

## `TlsConfig`

```dart
TlsConfig({ bool enabled, bool verifyCertificate = true, SecurityContext? securityContext });
```

Pass to `connect`/`withConnection` to negotiate TLS before the TNS handshake.
`verifyCertificate: false` accepts self-signed certs (development only).

## Minimal example

```dart
import 'package:oracledb/oracledb.dart';

await OracleConnection.withConnection(
  'localhost:1521/FREEPDB1',
  user: 'system',
  password: 'oracle',
  callback: (conn) async {
    final r = await conn.execute(
      'SELECT id, name FROM employees WHERE dept = :d',
      {'d': 10},
    );
    for (final row in r.rows) {
      print('${row['ID']}: ${row['NAME']}');
    }

    await conn.runTransaction((tx) async {
      await tx.execute(
        'INSERT INTO employees (id, name, dept) VALUES (:i, :n, :d)',
        {'i': 1, 'n': 'Ada', 'd': 10},
      );
    });
  },
);
```

See `example/example.dart` and the README "Usage" section for PL/SQL, LOB, JSON,
and TLS examples.
