### Diff-scope review (bmad-review, `lib/` diff). Findings re-checked where marked.

- **F3 (FIX): REF CURSOR OUT bind and nested `CURSOR()` columns with a native JSON column fail on 21c with `ORA-00600 [kollAdjustDuration ...], [119]`.** `_implicitResultRequiresDefine` (`connection.dart:1076`) is applied only to implicit results (`:1146`, `:1247`). `_wrapRefCursorOutBinds` (`:829-843`) and `_drainNestedCursor` (`:1026-1043`) do not use it. The verification-gap reviewer reproduced it live (23ai passes, 21c fails, implicit-result control passes on 21c). No test covers JSON in these shapes. DW-2 tracks only the LOB variant. Reviewer-reported; live probe not re-run by me.
- **F4 (FIX): default-on BLOB `IS JSON` / `IS OSON` to `Map`/`List` decode is a behaviour change with no opt-out.** `transport.dart:2130-2137`. CHANGELOG line 73 admits "used to return the raw `Uint8List`". Two reviewers independently flagged that the story's node-oracledb parity claim is incomplete. In the reference, the converter is gated by `oldJsonColumnAsObj`, default `false` (`reference/node-oracledb/lib/future.js:36`, re-checked by me). The change sits under `## Unreleased` at `pubspec.yaml` version 1.4.0.
- **F5 (FIX): four hand-copied "needs LOB define / is LOB-like" predicates disagree.** `connection.dart:704` and `:3715` test CLOB and BLOB only. `:1079-1081` and `transport.dart:1086-1091` also test JSON (re-checked). Consequence: the fetchLobs reject guard and cached-cursor re-parse ignore a native JSON column.
- **F6 (FIX): `preserveTimestampTimeZone` is dropped on the top-level DEFINE round** (`transport.dart:2518-2539`, `sendExecute` call at `:1093-1099`). The first batch yields `DateTime` and later batches `OracleTimestampTz`. This is DW-3, now a roughly two-line fix. It is also untested for the real `Transport.defineCursor` (stubs only: `result_set_cursor_json_blob_test.dart:81-91`, `implicit_result_set_test.dart:144-152`).
- **F7 (DEFER, high-risk, unverified): LOB or JSON plus nested `CURSOR()` implicit result past the prefetch window.** `result_set_cursor.dart:479-505` clears `_requiresFullExecute` after the DEFINE, so continuations are plain OFETCH. Matches DW-4. Needs a live fixture with rows above prefetch.
- **F8 (DEFER, unverified): two empty DEFINE/FETCH batches would end `nextRowData` early** (`result_set_cursor.dart:506-524`). Matches DW-5.
- **F9 (FIX): text-JSON path returns `double` where the OSON path returns `int`.** `oson.dart:1140` (`jsonDecode`) vs `:884-888` (`decodeNumber`). `{"q":1.0}` and `1e2` give different Dart types for the same logical document depending on storage. A text `1e999` becomes `Infinity` and now re-binds (13.3 accepts non-finite as BINARY_DOUBLE). Cross-story 13.2 x 13.3 interaction.
- **F10 (FIX): bind-side validation gaps.**
  - No depth or cycle guard in `_assertValidJsonMember` (`oson.dart:155-200`): a self-referencing Map raises `StackOverflowError`, not `ArgumentError`.
  - Validation is repeated up to 3 times per document.
  - `DateTime` with `isUtc` is written as a zone-less TIMESTAMP (`oson.dart:544-556`).
  - A declared-JSON `String` or `Uint8List` root now binds as a JSON scalar, so `jsonEncode(map)` is silently double-encoded.
  - NaN and ±Infinity are accepted by default (`oson.dart:158`).
- **F11 (FIX): `utf8.decode` `FormatException` escapes `decodeOson`** (`oson.dart:858, 879-883, 948`), which wraps only `BufferException`. It violates the documented "throws `OracleException`" contract.
- **F12 (FIX): a fetched OSON v3 document with a field name over 255 bytes cannot be re-bound.** `oson.dart:183-190` rejects such keys while the decoder accepts them. This contradicts the doc claim "a fetched document always re-binds".
- **F13 (DEFER): the decoded `Map`/`List` is shared across aliased cells, including across batches via `_previousRoundLastRow`** (`result_set_cursor.dart:581`). The cross-batch case was not covered by the triage, which rejected only the within-call alias. Reviewer-reported.
- **F14 (DEFER):** `materializeLobs(columns:)` is optional, so a future call site that omits it returns raw bytes silently (`transport.dart:1299-1313, 2130`). One bad row fails the whole query with no row ordinal (`transport.dart:2143-2161`). The public `isJson`/`isOson` getters do not express the actual decode rule (`execute_message.dart:1101-1107`). The DEFINE buffer size for types outside the switch falls to `maxLength` or 1 (`execute_message.dart:659-700`, unverified).
- **F15 (ACCEPT, recorded): 12c compatibility is unproven live.** The UDS flag values 0x100/0x800 were measured only on 21c and 23ai (`constants.dart:188-201`). README names 21c and 23ai as validated. Map/List binds are sent as wire type 119 with no server-version gate, so on pre-21c servers the read path is promised but the write path cannot work (reviewer-reported).
- **F16 (DEFER): the same `ledger-drift` pattern as Epic 12.**
  - `deferred-work.md` DW-4 and DW-5 lost their severity lines. The 13-2 frontmatter had `medium (unverified)` and `high (unverified)`; the ledger shows `severity:` only on DW-1, 2, 3 and 6 (diff vs `7f9bd94^`).
  - `doc/architecture.md:71` still says `execute_message.dart (~1767 LOC)`; the file is 3020 lines.
